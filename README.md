# TMS Training App

REST API приложение для управления тренировочными программами.
Проект реализован на **Django + Django REST Framework** и позволяет работать с пользователями, тренировками, планами тренировок, отзывами и уведомлениями.

Проект создан в учебных целях для практики разработки backend-приложений, архитектуры Django-проектов и написания тестов.

---

# Основной функционал

Приложение предоставляет API для работы со следующими сущностями:

### Пользователи (Users)

* регистрация пользователя
* аутентификация
* управление профилем
* сигналы Django для обработки событий пользователя

### Планы тренировок (Plans)

* создание тренировочных планов
* редактирование планов
* получение списка тренировочных программ

### Тренировки (Workouts)

* добавление тренировок
* просмотр тренировок
* связь тренировок с тренировочными планами

### Отзывы (Reviews)

* пользователи могут оставлять отзывы
* просмотр отзывов

### Уведомления (Notifications)

* система уведомлений для пользователей
* возможность расширения для интеграции с внешними сервисами

# Установка проекта

## 1. Клонировать репозиторий

```bash
git clone <repo_url>
cd tms_training_app
```

## 2. Установить зависимости

Проект использует **Poetry**.

```bash
poetry install
```

Активировать виртуальное окружение:

```bash
poetry shell
```

---

# Запуск проекта

Применить миграции:

```bash
python manage.py migrate
```

Создать суперпользователя:

```bash
python manage.py createsuperuser
```

Запустить сервер:

```bash
python manage.py runserver
```

API будет доступно по адресу:

```
http://127.0.0.1:8000/
```

---

## Запуск через Docker

В проекте используется **docker-compose** для запуска инфраструктурных сервисов.

Файл `docker-compose.yml` поднимает следующие контейнеры:

* PostgreSQL — основная база данных
* Redis — кэш и брокер сообщений
* Memcached — дополнительный слой кэширования

### Запуск инфраструктуры

```bash
docker-compose up -d
```

После запуска будут доступны сервисы:

| Сервис     | Порт  |
| ---------- | ----- |
| PostgreSQL | 5432  |
| Redis      | 6379  |
| Memcached  | 11211 |


### Проверка подключения к сервисам

Django будет использовать следующие подключения:

**PostgreSQL**

```
HOST=localhost
PORT=5432
DB_NAME=training
USER=training_user
PASSWORD=training_pass
```

**Redis**

```
redis://localhost:6379
```

**Memcached**

```
127.0.0.1:11211
```
